# InfiSheet 界面可用性调整方案

## 状态

提案。本文只定义界面与交互调整范围，不改变画布数据、工作流生成、MCP 或 ComfyUI 通信逻辑。

## 背景与目标

当前深色画布的视觉风格统一，但高频入口以小尺寸纯图标为主。新用户不容易判断从哪里开始，熟练用户也需要记忆底部工具栏中各图标的含义。

本轮目标：

- 提高图标、文字和状态的可辨识性；
- 增大点击热区，降低无限画布上的误点与误拖；
- 把高频操作显式展示，低频操作收纳；
- 提供明确的空画布起始路径；
- 保持现有紧凑、专业的深色画布风格。

## 约束

- 不改变既有快捷键与画布操作语义。
- 不引入运行时依赖或构建步骤。
- 不改变项目快照 schema、API 或服务端接口。
- 桌面端优先；窄屏下允许将低频操作收纳进菜单。

## 设计决策

新增“界面密度”设置，默认使用“舒适模式”，同时保留“紧凑模式”。舒适模式解决可读性与可点击性问题；紧凑模式保留目前高信息密度的工作方式，避免强制改变熟练用户习惯。

| 项目 | 舒适模式（默认） | 紧凑模式 |
|---|---:|---:|
| 主图标 | 20px | 18px |
| 次级图标 | 18px | 16px |
| 主按钮热区 | 40 x 40px | 36 x 36px |
| 次级按钮热区 | 36 x 36px | 32 x 32px |
| 默认正文 | 14px | 13px |
| 核心入口 | 图标 + 文字 | 以图标为主 |

间距统一使用 4 / 8 / 12 / 16px 栅格。图标按钮必须具备 tooltip、键盘焦点态与 `aria-label`；颜色不得是唯一的状态表达方式。

## 顶部导航栏

### 目标结构

```text
[首页] [项目名 ▾] [素材] [工作流] [设置]
                    [已保存]
       [ComfyUI：在线 ▾] [队列：0] [MCP：未连接]
```

### 调整内容

- 首页可保持纯图标；项目、素材、工作流、设置使用图标加短文字。
- 项目名称为左侧最高层级信息，应比普通导航项更突出。
- 保存状态只显示“已保存 / 正在保存 / 保存失败”；时间信息移至 tooltip。
- ComfyUI 使用文字、图标与颜色三重状态：`在线`、`生成中`、`未连接`。
- MCP 默认显示简短状态；已连接后再在 tooltip 或弹层中展示客户端名称、连接时间与调用次数。

## 底部画布工具栏

### 目标结构

```text
[＋ 新建] [选择] [连线] [分组] │ [视图 ▾] │ [撤销] [重做] [帮助]
```

### 调整内容

- `＋ 新建` 是唯一的高对比主按钮，点击菜单包含：图片生成、提示词、工作流、导入图片。
- 选择、连线、分组为高频操作，使用图标与文字，或在舒适模式下至少提供常驻文字。
- 网格、连线显示、小地图、适配画布、缩放等归入“视图”菜单。
- 撤销与重做保持可见；不可用时禁用但保留 tooltip。
- 宽度不足 1024px 时，低频项自动进入“更多”，但新建、选择、连线、撤销必须持续可见。

## 空画布引导

空画布不只显示弱提示，改为可关闭的引导卡：

```text
开始创作

[ 图片生成 ]  [ 导入工作流 ]
[ 添加提示词 ] [ 打开最近项目 ]

也可以双击空白画布，快速添加节点
```

- “图片生成”为主按钮。
- 创建首个节点后自动隐藏。
- 帮助菜单提供“重新显示新手引导”。
- ComfyUI 不可用时，生成入口仍可点击，但下一步应明确说明连接状态并给出设置入口。

## 图片节点工具栏

图片编辑类操作默认使用“图标 + 文字”，避免用户通过纯图标猜测功能。

```text
[裁剪] [调色] [遮罩] [扩图] [下载] [更多编辑 ▾]
```

“更多编辑”收纳旋转、擦除、去字、抠图、高清等低频操作。

- 会创建节点的操作标注“将在新节点中生成”。
- 需要调用 ComfyUI 的操作标注“需要生成”。
- 长耗时操作提供进度、取消入口与可定位的失败信息。
- 紧凑模式可隐藏文字，但 tooltip 与无障碍标签仍必须保留。

## 设置入口

新增：`设置 → 外观 → 界面密度`

- 舒适模式（默认）：更大图标、40px 主热区、核心入口带文字。
- 紧凑模式：较小尺寸、更多纯图标入口。
- 配置保存在既有本地设置中，不影响画布内容与工作流。

## 实施顺序

1. 建立全局尺寸、间距、对比度与焦点态 token。
2. 改造底部工具栏与“新建”菜单。
3. 加入空画布引导卡与帮助中的重播入口。
4. 改造顶栏状态与图片节点工具栏。
5. 增加界面密度设置，并完成窄屏收纳策略。

## 验收标准

- 舒适模式下，主操作按钮热区不小于 40 x 40px，次级操作不小于 36 x 36px。
- 纯图标控件均具备 tooltip、清晰焦点态与 `aria-label`。
- 1440 x 900 与 1024 x 768 下，Dock 不遮挡缩放控件或小地图。
- 空画布用户无需了解“双击创建节点”，也能找到图片生成入口。
- 保存、ComfyUI 与 MCP 状态均能仅凭文字/图标辨识。
- 不改变既有快捷键、画布交互、项目数据与服务端 API。
