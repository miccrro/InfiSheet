双击画布 自由生成节点
教程与快捷键

建节点　双击画布空白，或底部 ＋；也可把图片文件拖进来。

连线　从节点右侧圆点拖到另一节点左侧圆点（文本→文本插槽、图片→图片插槽、工作流→输出）。

运行　工作流节点上的「运行」；图片节点选中后在下方生成器里直接出图。

框选　拖画布空白处直接框选（Shift 拖为加选）；点空白取消选择。

平移 / 缩放　空格拖 或 中键拖 平移，也可开底部的「移动」模式；滚轮缩放、F 适配。

复制节点　Alt + 左键拖动 直接拖出一个副本（原节点留在原地，松手落位）；也可以 Ctrl+C / V、Ctrl+D 创建副本。

多选 / 打组　Shift 点选加选，Ctrl+G 打组，Delete 删除。

工作流要用 API 格式：在 ComfyUI 里跑一次，再从「生成历史」导入最稳。

选择工作流

粘贴 API 格式工作流（ComfyUI 菜单：工作流 → 导出(API)），或选择本地文件。
